原生 Android 终端，内置离线 Debian 13.7 Trixie，支持 Android 8.0+ ARM64，无需 root 或 Termux。

修复终端视图初始化顺序导致的启动闪退。崩溃日志改为同步落盘，避免进程退出时丢失。

重新细化双行按键区：更紧凑的高度、独立绘制的方向箭头、统一字体基线与留白、轻边界，以及区分一次启用和锁定的修饰键状态。

整体界面随配色主题切换，包括标签、按键、设置弹窗与系统栏。精简设置导航与数值控件，标签移除圆点并使用小圆形关闭按钮。背景图片合并为一个入口，支持更换与清除。

修复终端默认背景擦除和透明度声明，处理动态终端界面重绘后的文字叠影与残留。背景色同步支持程序的 OSC 11 设置；图片背景继续使用透明合成。增加真实 Canvas 绘制回归检查。

- 顶部多标签、长按改名、关闭确认，前台服务维护会话。
- 双行可定制功能键、Ctrl/Alt/Shift 组合、修饰键锁定、方向键长按连发及 Bash 历史。
- 四套配色、自定义颜色、字体及背景图导入、字号、光标、背景遮罩。
- 记录搜索与导出、多行粘贴确认、文件导入、滚动缓冲配置、本地诊断日志。

首次打开需要展开约 315 MB 系统文件，请保留至少 500 MB 可用空间。Android 可能提示应用目标版本较旧，这是可执行 Linux 用户空间对 targetSdk 28 的兼容性要求。

GitHub Actions 执行编译、单元测试、Lint 和签名检查。界面与交互尚需真机验收，未使用模拟器作视觉验收。

PRoot 无法运行 Docker、systemd 或独立 Linux 内核。后台任务受 Android 进程与电池策略约束。
